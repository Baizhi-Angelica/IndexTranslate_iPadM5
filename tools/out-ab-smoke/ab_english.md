> “残留 {n}”= 还原后最终译文里仍残留的 `{数字}` 占位符（必须为 0）；“丢失”= 模型把占位符删了/改成无法识别的形式；“变体”= 占位符被写成 `{ 0 }`、`{0 }` 等带空格形式（还原逻辑容忍并计数，不算错误）。

## 占位符异常样本（残留 / 丢失 / 重复 / 残留花括号）

无。S3/S4 所有样本的占位符都能完整还原，没有残留 `{n}`、丢失或重复。

## 占位符空格变体

没有出现 `{ 0 }` / `{0 }` 之类的空格变体，模型都按 `{n}` 原样输出。
